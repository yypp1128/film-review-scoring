# 影视评论自动评分系统

这是工程实践的基础实验版本。输入中文评论，预测三类情感及一至五星期望评分；导入多部作品的 CSV，展示作品均分、平滑评分、评论数及情感分布。

## 最简单的使用方式

1. 先打开本文件夹中的 `先看这里.txt`。
2. 双击 `启动系统.cmd`。已附训练模型时，无须再次下载数据或训练；首次运行可能需要安装依赖并联网。
3. 在浏览器中进入提示的本地地址，通常为 http://localhost:8501 。关闭命令窗口即可停止。
4. 在“单条影评”试用；在“作品看板”勾选随附真实测试集体验；在“实验结果”查看真实指标。

系统只绑定本机地址，不对外发布。用户评论仅在本地处理。

## 开发与复现

建议 Python 3.9 至 3.12。Windows 中打开终端进入本目录：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe prepare_data.py --movies 40
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

有配套数据时，可跳过下载步骤。`requirements-lock.txt` 记录本次实际运行环境，跨 Python 版本时优先使用 requirements.txt。

## 数据与使用范围

来源：https://github.com/bbublm/Douban-Movie-Review-Dataset 。发布者说明仅供学术研究和个人学习，禁止商业使用；此说明不代表影视平台额外授权。不要将数据作为自己的采集成果，也不要公开发布原始数据或宣称自己获得平台授权。

采样固定为提交 `83ce1656fc1ad7e61479d40178f7cd05f06a884b` 下 `data_all/` 中 20 KB 至 150 KB 的 CSV，以种子 42 打乱后选取 40 部。不是随机抽取平台用户，不能代表全平台口碑。实际采集日志见 `data/provenance.json`，记录原文件路径及 Git blob SHA。下载脚本会校验文件内容并缓存成功下载；网络失败可重跑。GitHub 未登录 API 存在访问频率限制，遇限额须待恢复后重试。

原数据没有表头，字段为时间、用户名、评论、星级、星级描述、点赞数、发布者预计算情感分数。处理后仅保留作品标识、作品名、文本、星级、时间和来源。用户名以及预计算情感分数均不进入标准训练数据，模型只读取文本。

## 模型与评价

- 清洗 HTML、空值、超短或超长评论，按去空白后的正文精确去重，保留否定词。尚未实现语义近重复识别。
- 按作品约 70/15/15 分组为训练、验证和测试，固定随机种子 42；相同作品不跨集合。训练集独立拟合字符二至四元组 TF-IDF。
- 三分类情感标签由星级生成：一二星为负向、三星为中性、四五星为正向，属于弱标签，尚未完成独立人工复核。
- 对比多项式朴素贝叶斯和两组 C 参数的逻辑回归。依据验证 Macro-F1 选择情感模型；五星模型比较两组 C 和有无类别平衡，依据验证 MAE 选择。开发期间曾查看固定测试结果，因此当前指标为探索实验，正式验收仍需新作品留出复验。
- 一至五星概率的加权和为预测星级；按作品取均值，平滑方法为 `(n*A + 20*C)/(n+20)`，其中 C 为训练集平均星级。十分值为星级乘二，范围 2 至 10。
- 平滑先验强度为固定展示参数，不声称为最优；测试结果同时报告平滑前后误差。

## 上传文件格式

```csv
movie_id,movie_name,text
my_movie,自己的作品,演员表演自然故事很感人
my_movie,自己的作品,剧情拖沓不值得看
```

预测只要求 text，训练要求额外提供 1 至 5 整数的 star，以及至少 10 部作品的 movie_id。CSV 使用 UTF-8 编码。界面上限为 20 MB、50000 条评论；正文有效长度为 2 至 5000 字。重复评论默认保留第一条，跨作品相同文本也只留一条。

## 实践尚需补齐的内容

基础版本不等于全部实践验收完成。尚需结合导师要求决定并完成：独立人工标签复核、许可条件下的影视平台直接采集实测、语义近重复检查、更多作品与交叉验证；有条件再加入 BERT 对照。当前没有 BERT 结果，不把其写成已完成实验。公开数据下载不能冒充自己直接爬取平台的成果。

`collect_page.py` 已实现单页解析与访问条件检查，使用静态页面片段测试了解析逻辑，尚未验证线上页面采集。实际使用前须确认平台当前规则和使用条件，robots 允许也不代表数据使用授权。示例命令为 `python collect_page.py --url https://movie.douban.com/subject/1292052/comments --name 肖申克的救赎`，默认不翻页，不使用账户、代理或验证码绕过。
