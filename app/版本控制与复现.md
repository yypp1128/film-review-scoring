# 版本控制与复现

本仓库为影视评论自动评分系统的课程交付源码。网页支持 MacBERT 与字符级 TF-IDF 加逻辑回归的同样本对照。版本控制覆盖源码、测试、依赖说明、公开语料来源清单和汇总评测。数据正文、逐条预测、盲标样本、训练权重及本机 Python 环境通过项目本地文件管理。

## 版本基线

- `v1.0.0` 为 TF-IDF 增强版。此标签指向根据留存源码归档的接入前快照，包含单条评分和批量看板。
- `v2.0.0` 为 MacBERT 网页版。默认使用 MacBERT，可切换到 TF-IDF 做对照。主分支 `main` 承载此版本。
- 使用 `git log --first-parent --oneline --decorate main` 查看两个课程版本。最初纳管的提交也作为交付历史保留。
- 代码仓库建立前的开发快照由实验报告和项目备份保留。Git 历史从首次纳管时起记录。
- 修改训练流程或模型时，存档新配置、数据版本和汇总指标。修改输入输出契约时，同步更新测试与交互说明。

## 复现步骤

1. 以 Python 3.9 至 3.12 安装 `requirements.txt`。为 MacBERT 单独使用 Python 3.11、可用的 PyTorch CUDA 环境与 Transformers 4.51.3。
2. 执行 `python prepare_data.py --movies 40` 和 `python train.py` 生成基础模型。再执行 `python prepare_data.py --expanded` 和 `python train_enhanced.py` 生成 TF-IDF 增强模型。下载脚本使用固定公开源提交，并校验数据文件。样本及模型的相关说明见仓库来源记录。
3. 按《MacBERT使用说明》准备官方配置、词表和预训练权重，然后执行 `python train_macbert.py`。基线训练与评估要求本地模型目录和数据文件已准备。
4. 在含所选模型依赖的 Python 环境中执行 `python -m streamlit run app.py --server.address 127.0.0.1`。在已有项目电脑上也可运行 `启动系统.cmd`。
5. 执行 `python -m pytest -q`。应用测试依赖本地基线制品和随附测试样本，尚未训练时会跳过应用用例。

查看 `reports/macbert/MacBERT对照实测报告.md` 可核对两种模型在相同作品集合上的结果。
