# 运行与复现

## 使用已训练的交付包

进入正式交付目录中的版本一或版本二，双击外层的「启动系统.cmd」。两版分别使用本机端口 8511 和 8512。版本二默认 MacBERT，可以切换为 TF-IDF 做对照。

演示时可先分析一条中文影评，再在「作品看板」上传 UTF-8 CSV。必需列为 text，可选列为 movie_id 和 movie_name。看板提供作品评分和逐条明细两份下载。「实验结果」显示固定测试集上的模型对照。

## 从 GitHub 源码启动

在当前仓库的 main 分支，先进入 app 目录。通过历史版本标签下载的源码可在其根目录执行同样的命令。

```powershell
cd app
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

启动前应准备已训练的本地模型。TF-IDF 使用 models/enhanced.joblib。MacBERT 使用 models/macbert 中的打包权重、配置、词表和评分参数，并需要 PyTorch、Transformers 与 Safetensors。完整网页和复训环境见 [MacBERT 使用说明](../app/MacBERT使用说明.md)。

## 数据、训练与测试

1. 运行 `python prepare_data.py --movies 40` 并执行 `python train.py` 生成基础实验制品。
2. 运行 `python prepare_data.py --expanded` 及 `python train_enhanced.py`，得到增强版评分模型和评测样本。
3. 按 MacBERT 使用说明准备官方预训练权重，再运行 `python train_macbert.py`。
4. 执行 `python -m pytest -q`。程序测试使用已生成的模型和测试样本。
